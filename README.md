# السوق العقاري | Real Estate Hub

منصة متكاملة لعرض وتحليل الصفقات العقارية المعتمدة ومؤشرات السوق العقاري لحظة بلحظة. تم بناء المشروع وتطويره انطلاقاً من تصميم Figma المعتمد مع الالتزام الكامل بنظام التصميم (Design System) والخطوط والألوان والرموز.

## 🌟 المميزات

- **نظام تصميم احترافي**: مبني على خط **Cairo** المخصص للغة العربية، وألوان العلامة التجارية الرسمية (`#d66043`, `#f6795a`, `#141414`).
- **واجهة كاملة RTL**: دعم أصيل للغة العربية من اليمين إلى اليسار.
- **أقسام متكاملة**:
  - **شريط التنقل (Navbar)**: شفافية زجاجية مع الشعار وروابط التنقل وأزرار تسجيل الدخول وإنشاء الحساب.
  - **القسم الرئيسي (Hero)**: عرض مجسم ثلاثي الأبعاد مع بطاقات تفاعلية لمؤشرات الصفقات اليومية ومتوسط سعر المتر.
  - **المميزات الرئيسية (Features)**: مقارنة الصفقات بأعمدة بيانية، ومؤشر حركة الأسعار الأسبوعي، والرؤى التحليلية.
  - **لوحة التحكم الحية (Platform Showcase)**: جدول الصفقات المعتمدة مع التحديث اللحظي وفلاتر العقارات.
  - **الإحصائيات الموثقة (Statistics)**: دقة المطابقة، متوسط وقت البحث، وعمليات البحث الناجحة.
  - **الخدمات والخريطة التفاعلية (Services & Maps)**: استكشاف الخريطة الحية ونقل الملكية والمؤشرات.
  - **البحث المدعوم بالذكاء الاصطناعي (AI Search CTA)**: بطاقات المقارنة التلقائية والتحليل الذكي.
  - **تذييل الصفحة (Footer)**: روابط سريعة ومعلومات التواصل والترخيص الرسمي.
